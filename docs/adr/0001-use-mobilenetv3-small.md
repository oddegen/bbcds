# ADR 0001: Use MobileNetV3-Small

Status: Accepted for future product work.

Use a project-owned MobileNetV3-Small model with 224 by 224 input for the prototype when model implementation begins. The model taxonomy is `Safe`, `Suggestive`, `Explicit`, and `Explicit Illustration`.

Model artifacts require documentation updates, release evidence, and benchmark evidence before commit or publication.
